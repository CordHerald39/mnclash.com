Clash 订阅链接怎么用

订阅链接是使用 Clash 的第一步。拿到订阅链接后，导入到 Clash 就能自动获取所有节点配置，不用一个个手动添加。这篇文章从零开始，详细讲解订阅链接的获取、导入、更新和管理。

什么是订阅链接

订阅链接是一个网址，里面包含了所有节点的配置信息。把这个链接导入 Clash 后，软件会自动解析出所有节点、规则、代理组等配置。

一个典型的订阅链接长这样：

https://example.com/api/v1/client/subscribe?token=abcd1234efgh5678

订阅链接的好处：

  • 一次导入，获取所有节点
  • 机场更新节点后，点一下刷新就能同步
  • 包含优化好的规则和配置
  • 换设备时只需要导入同一个链接

如何获取订阅链接

订阅链接由代理服务提供商（俗称"机场"）提供。购买服务后，机场会给你订阅链接。

注册并购买服务

找一个靠谱的机场，注册账号并购买套餐。价格从每月十几元到上百元不等，根据流量和节点数量定价。

进入用户中心

登录机场网站，找到"用户中心"、"我的订阅"或类似入口。

复制订阅链接

找到 Clash 订阅链接（有些网站叫"Clash 订阅"、"通用订阅"、"标准订阅"），点击"复制"按钮。

注意完整复制整个链接，不要漏掉前后的字符。

重要提示：订阅链接包含你的账号信息，不要泄露给别人。别人拿到你的订阅链接就能用你的流量。

如何导入订阅链接

不同平台的 Clash 客户端导入方法略有不同，但流程基本一样。

Windows - Clash for Windows / Clash Verge

打开配置界面

Clash for Windows：点击左侧的"Profiles"标签

Clash Verge：点击左侧的"订阅"或"配置"标签

添加订阅

找到"从 URL 导入"或"Download from a URL"按钮，点击它。

粘贴链接

在弹出的输入框中粘贴订阅链接，给这个配置起个名字（比如"我的订阅"），点击确定或下载。

等待下载

Clash 会自动连接订阅链接，下载配置文件。下载完成后，配置会出现在列表里。

选择配置

点击刚下载的配置，让它处于选中状态。有些客户端会自动切换，有些需要手动点击"使用"。

macOS - ClashX / ClashX Pro

打开配置管理

点击菜单栏的 ClashX 图标，选择"配置" → "托管配置" → "管理"。

添加订阅

在托管配置窗口，点击左下角的"+"按钮。

输入信息

在弹出的窗口中：

  • URL：粘贴订阅链接
  • 配置名称：起个名字，比如"我的订阅"
  • 点击"确定"

选择配置

回到主菜单，"配置" → 选中你刚添加的配置。

Android - Clash Meta

打开配置界面

点击顶部的"配置"或"Profiles"。

添加订阅

点击右上角的"+"按钮，选择"从 URL 导入"。

填写信息

  • 名称：起个名字
  • URL：粘贴订阅链接
  • 自动更新间隔：可以选择"每天"
  • 点击"保存"

选择配置

在配置列表中点击刚添加的配置，让它处于选中状态。

iOS - Shadowrocket

复制订阅链接

在 Safari 或其他浏览器中复制订阅链接。

导入到 Shadowrocket

打开 Shadowrocket，点击右上角的"+"，选择"Subscribe"。

填写信息

  • URL：粘贴订阅链接（会自动填充）
  • 备注：起个名字
  • 点击"完成"
快速导入技巧：有些机场提供一键导入功能。你在机场网站点击"一键导入 Clash"，会自动跳转到 Clash 并完成导入，不需要手动复制粘贴。

导入失败怎么办

如果导入订阅时提示失败或下载不了，试试这些办法：

问题 1：提示"无法连接到订阅链接"

原因：有些订阅链接本身需要代理才能访问。

解决：

  • 关闭 Clash 的代理（如果已开启）
  • 或者用浏览器打开订阅链接，看能不能访问
  • 如果浏览器也打不开，联系机场确认链接是否正确

问题 2：导入后没有节点

原因：订阅链接过期、服务到期、或 Clash 版本不支持订阅中的协议。

解决：

  • 确认服务是否在有效期内
  • 联系机场确认订阅链接是否正确
  • 升级到最新版本的 Clash 或换用 Clash Meta

问题 3：链接复制不完整

症状：粘贴后发现链接很短，或者缺了一截。

解决：重新复制，确保完整复制整个链接。有些机场的链接很长，容易漏掉后面的参数。

如何更新订阅

机场可能会添加新节点、移除失效节点、或调整配置。定期更新订阅能获取最新的节点列表。

手动更新

Windows / macOS：在配置列表中，找到你的订阅，点击旁边的刷新或更新图标。

Android：长按配置，选择"更新"。

建议更新频率：每周一次，或者发现节点不好用时更新。

自动更新

部分 Clash 客户端支持自动更新订阅：

  • Clash Verge：在订阅设置中可以设置自动更新间隔（每天/每周）
  • Clash Meta (Android)：添加订阅时可以选择自动更新间隔
注意：更新订阅时最好先关闭代理，有些订阅链接在开着代理时更新会失败。

订阅管理技巧

多订阅管理

如果你有多个机场订阅，可以都导入到 Clash：

  • 给每个订阅起个清晰的名字（比如"机场A"、"机场B"）
  • 切换时点击对应的配置即可
  • 同时只能启用一个订阅

备份订阅

订阅链接建议保存在安全的地方：

  • 存到密码管理器（如 1Password、Bitwarden）
  • 或者存到私人笔记里
  • 换设备时直接用同一个订阅链接导入

订阅转换

有些机场只提供 V2Ray 订阅，不提供 Clash 订阅。这时可以用订阅转换服务：

  • 把 V2Ray 订阅链接输入转换工具
  • 生成 Clash 兼容的订阅链接
  • 常用转换工具：sub-web、订阅转换 API
安全提醒：使用第三方订阅转换服务时，你的订阅链接会被第三方服务器处理。选择信誉好的转换服务，或者自己搭建转换服务器。

常见问题

Q: 订阅链接可以在多个设备上使用吗？
可以。同一个订阅链接可以导入到手机、电脑等多个设备。但要注意流量是共享的，多设备同时使用会消耗更多流量。
Q: 订阅链接会过期吗？
订阅链接本身通常不会过期，但如果你的服务套餐到期了，订阅链接会失效或返回空节点。续费后订阅链接通常还是同一个。
Q: 更新订阅会影响当前连接吗？
不会。更新订阅只是下载新的配置文件，不会断开当前的代理连接。但如果你当前使用的节点在新配置中被删除了，可能需要重新选择节点。
Q: 可以手动编辑订阅配置吗？
可以，但不建议。如果手动编辑了订阅配置，下次更新订阅时你的修改会被覆盖。如果需要自定义配置，建议创建一个本地配置文件，不要直接改订阅。

总结

订阅链接的使用流程：

  1. 从机场获取订阅链接
  2. 在 Clash 中导入订阅
  3. 选择刚导入的配置
  4. 选择一个节点
  5. 开启系统代理
  6. 定期更新订阅（建议每周一次）

掌握订阅链接的使用，是用好 Clash 的第一步。遇到问题先检查订阅链接是否正确、服务是否到期、网络是否正常，大部分问题都能解决。
