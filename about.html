关于 Clash

Clash 是一款开源的网络代理工具，最初由 Dreamacro 开发。它的核心理念是通过规则引擎实现智能分流，让用户能精准控制网络流量走向。不同于传统 VPN 的一刀切，Clash 能根据域名、IP、地理位置等条件灵活分配流量，既能访问外网，又不影响国内网站速度。

发展历程

2018 年

Dreamacro 发布 Clash 第一个版本，基于 Go 语言开发。最初只支持 Shadowsocks 协议，但已经实现了规则分流的核心功能。

2019-2020 年

Clash 逐渐增加对 VMess、Trojan、Snell 等协议的支持。图形界面客户端 Clash for Windows 和 ClashX 相继出现，大大降低了使用门槛。Clash 开始在技术圈流行起来。

2021 年

Clash Premium 发布，加入了 TUN 模式、规则集订阅、Script 脚本等高级功能。同期，Clash Meta 项目启动，作为社区驱动的增强版内核。

2022-2023 年

原作者 Dreamacro 停止维护 Clash 和 Clash Premium。Clash Meta 更名为 Mihomo，成为最活跃的内核分支，持续增加新协议支持（Hysteria2、TUIC、VLESS+Reality）。

2024-2026 年

Mihomo 内核成为事实标准，各平台客户端纷纷切换到 Mihomo。Clash 生态持续繁荣，出现了 Clash Verge、Clash Nyanpasu、Mihomo Party 等新一代客户端。

核心技术特点

基于规则的智能分流引擎

这是 Clash 最核心的功能。传统代理工具要么全局代理，要么完全不代理，而 Clash 能根据规则精确控制每条流量：

  • 域名匹配：可以指定某些网站走代理，某些直连。比如 Google、GitHub 走香港节点，Netflix 走美国节点，淘宝、微信直连。
  • IP 匹配：根据目标 IP 地址或 IP 段判断流量走向。配合 GEOIP 数据库，能自动识别国内 IP 直连。
  • 进程匹配：根据应用程序名称决定是否走代理。某些客户端版本支持这个功能。
  • 规则优先级：从上到下依次匹配，命中第一条符合的规则后不再继续，保证了高效执行。

规则引擎让 Clash 能做到既访问外网又不影响国内服务，这是它比普通 VPN 好用的关键。

TUN 模式与虚拟网卡

系统代理只对遵守代理设置的应用有效，很多游戏和特殊软件不读取系统代理配置。TUN 模式解决了这个问题。

TUN（网络隧道）模式会创建一个虚拟网卡，把系统所有网络流量都重定向到这个虚拟网卡，由 Clash 接管。这样一来：

  • 游戏客户端能走代理，实现游戏加速
  • 命令行工具（git、npm、pip）自动走代理
  • UWP 应用和特殊软件也能代理

TUN 模式需要更高的系统权限，Windows 需要管理员权限，macOS 需要授权系统扩展。配置得当，能实现真正的透明代理。

DNS 分流与防污染

DNS 是网络访问的第一步，但也是最容易被干扰的环节。Clash 内置了 DNS 服务器，提供：

  • DNS 分流：国内域名用国内 DNS（快），国外域名用国外 DNS（准）
  • 防止污染：国外 DNS 查询走代理，避免返回错误 IP
  • Fake-IP 模式：返回假 IP 跳过 DNS 查询，直接开始连接，加速访问
  • 防止泄露：DNS 请求不走系统 DNS，避免暴露访问的网站

这些功能让 Clash 不仅仅是个代理工具，还是个智能 DNS 解析器。

支持的代理协议

Clash 支持主流的代理协议，Mihomo 内核支持的协议更多：

协议名称 特点 支持情况
Shadowsocks (SS) 经典协议，稳定可靠，部署广泛 完全支持
ShadowsocksR (SSR) SS 增强版，兼容性好 Mihomo 支持
VMess V2Ray 核心协议，功能丰富 完全支持
VLESS VMess 轻量版，性能更好 Mihomo 支持
Trojan 伪装成 HTTPS，隐蔽性强 完全支持
Hysteria / Hysteria2 基于 QUIC，高速低延迟 Mihomo 支持
Snell 高性能加密协议 完全支持
TUIC 新一代 QUIC 代理 Mihomo 支持
SOCKS5 / HTTP 标准代理协议 完全支持

一个 Clash 客户端就能管理所有这些协议的节点，不需要多个工具切换。

技术架构

Go 语言开发

Clash 使用 Go 语言编写，利用 Go 的并发特性，能高效处理大量网络连接。单核 CPU 就能稳定跑数千并发，内存占用低，适合长时间运行。

YAML 配置文件

配置文件采用 YAML 格式，结构清晰，易于阅读和编辑。支持订阅链接自动下载和更新，也支持手动编写复杂规则。

RESTful API

Clash 内置 RESTful API，可以通过 HTTP 接口控制代理行为、查询连接状态、切换节点。Web Dashboard 就是基于这个 API 实现的。

代理组策略

支持多种代理组策略：手动选择、自动测速选择最快节点、负载均衡、故障转移。可以把多个节点组合成策略组，灵活调度。

规则集订阅

除了节点订阅，规则也可以订阅。社区维护的规则集（如 ACL4SSR）定期更新，包含最新的分流规则和广告屏蔽规则。

流量统计

实时显示上传下载速度、每个连接的流量情况。可以看到哪些应用在走代理，每个节点消耗了多少流量。

Clash 生态系统

内核

目前主流的 Clash 内核有两个：

  • Clash - 原版内核，已停止更新，功能稳定但不再增加新特性
  • Mihomo（原 Clash Meta） - 最活跃的分支，持续更新，支持最新协议和高级功能

2026 年，大部分客户端都已切换到 Mihomo 内核，它是事实上的标准。

客户端

各平台有多款优秀的图形界面客户端：

  • Clash for Windows - 老牌 Windows 客户端，已停更但仍可用
  • Clash Verge - 新一代跨平台客户端，界面现代，功能全面
  • ClashX / ClashX Pro - macOS 原生客户端，Pro 版支持增强模式
  • Clash for Android / Clash Meta for Android - Android 平台首选
  • Clash Nyanpasu - 轻量级跨平台客户端
  • Mihomo Party - 基于 Mihomo 的新客户端

规则集

社区维护了大量规则集，可以直接订阅使用：

  • ACL4SSR - 最流行的规则集，分类详细
  • Loyalsoldier - GitHub 大佬维护，每日更新
  • lhie1 - 老牌规则集，兼容性好

Clash vs 其他代理工具

Clash vs V2RayN

V2RayN 专注 VMess/VLESS 协议，规则分流能力较弱。Clash 支持更多协议，规则引擎更强大，适合需要精细控制流量的用户。

Clash vs Shadowrocket

Shadowrocket 是 iOS 平台的优秀客户端，价格便宜（约 $3），兼容 Clash 配置。但只有 iOS 版本，其他平台还是需要 Clash。

Clash vs Surge

Surge 功能最强大，规则引擎、网络调试、模块系统都是顶级的。但价格昂贵（$50-$100），主要面向专业用户。Clash 免费开源，功能够用，性价比高。

Clash vs VPN

VPN 全局加密所有流量，Clash 可选择性代理。VPN 简单但不灵活，Clash 复杂但精准。日常使用 Clash 更方便，速度也更快。

为什么选择 Clash

开源免费 规则分流 多协议支持 全平台覆盖 社区活跃 配置灵活 性能优秀 持续更新

Clash 不是最简单的，也不是功能最多的，但它在易用性、功能性、开放性之间找到了很好的平衡点。对于需要稳定可靠代理工具的用户来说，Clash 是个很好的选择。

从软件开发者访问 GitHub、Stack Overflow，到科研人员查阅国际期刊，再到普通用户看 YouTube、用 ChatGPT，Clash 都能提供流畅的体验。而且开源的特性意味着它不会突然消失，社区接力维护能保证长期可用。
