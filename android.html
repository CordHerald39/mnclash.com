安装教程（以 Clash Meta for Android 为例）

下载 APK
访问 GitHub Releases 页面，下载最新版本的 APK 文件（选择 ClashMetaForAndroid.Meta.apk）。
允许安装
下载完成后，点击 APK 文件。如果提示"不允许安装未知应用"，点击"设置" → 打开"允许安装此来源的应用"开关 → 返回继续安装。
安装应用
点击"安装"按钮，等待安装完成后点击"打开"。
导入配置
打开应用，点击顶部"配置"标签，点击右上角"+"按钮，选择"URL"，粘贴你的订阅链接，点击"保存"。
选择节点
点击"代理"标签，在列表中选择想用的节点。可以点击节点右侧的图标测试延迟。
启动服务
返回"首页"标签，点击中间的电源图标启动代理。第一次使用会弹出 VPN 连接请求，点击"确定"授权即可。
安全提示：
  • 只从 GitHub 官方仓库或 F-Droid 下载 APK
  • 不要从不明来源的网站下载，避免安装到被修改的版本
  • 下载后检查文件签名（高级用户）

不同品牌手机的后台设置

国产手机系统对后台应用限制较严格，需要额外设置才能保证 Clash 持续运行。

小米 / Redmi（MIUI / HyperOS）

  • 打开"手机管家" → "应用管理" → 找到 Clash Meta
  • 打开"自启动"权限
  • 打开"后台运行"权限
  • 电池优化选择"无限制"

华为 / 荣耀（HarmonyOS / EMUI）

  • "设置" → "应用和服务" → "应用启动管理"
  • 找到 Clash Meta，关闭"自动管理"
  • 手动打开"允许自启动"、"允许关联启动"、"允许后台活动"

OPPO / vivo（ColorOS / OriginOS）

  • "设置" → "电池" → "应用耗电管理"
  • 找到 Clash Meta，选择"允许后台运行"
  • "设置" → "应用管理" → "权限管理" → "自启动" → 允许 Clash Meta

三星（One UI）

  • "设置" → "应用" → Clash Meta
  • "电池" → "优化电池用量" → 关闭优化

原生 Android / Pixel

  • 通常不需要额外设置
  • 如果锁屏后断开，进入"设置" → "应用" → Clash Meta → "电池" → 选择"不受限制"

代理模式说明

Clash 提供三种代理模式，根据需求选择：

1. 规则模式（Rule）- 推荐

根据配置文件中的规则自动分流。国内网站直连，国外网站走代理。这是最常用的模式，既能访问外网，又不影响国内网站速度。

2. 全局模式（Global）

所有流量都走代理。适合需要完全隐藏真实 IP 的场景，但会导致访问国内网站变慢。

3. 直连模式（Direct）

所有流量都不走代理。相当于关闭代理，适合临时需要使用真实 IP 的情况。

新手建议：99% 的情况下使用"规则模式"就够了。配置文件通常已经包含了常用的分流规则。

常见问题

Q: Clash Meta for Android 和 Clash for Android 有什么区别？

Clash Meta for Android 基于更新的 Clash Meta 核心，支持更多协议和功能。Clash for Android 已停止维护，不推荐使用。
Q: 为什么锁屏后代理会断开？

这是国产手机系统的后台限制导致的。按照上面"不同品牌手机的后台设置"部分进行设置即可解决。
Q: 订阅链接在哪里获取？

订阅链接由你的服务提供商提供。如果你没有服务，需要先购买或搭建自己的服务器。
Q: 可以同时安装多个 Clash 客户端吗？

可以，但同一时间只能运行一个。不同客户端之间的配置不互通，需要分别导入。
Q: FlClash 和 Clash Meta for Android 该选哪个？

功能上差不多。Clash Meta for Android 更稳定成熟，FlClash 界面更现代。新手推荐 Clash Meta for Android。

2026 年在 Android 上使用 Clash，首选 Clash Meta for Android。它是官方团队维护的，功能最完整，更新最及时，社区支持也最好。如果你喜欢更现代的界面，可以试试 FlClash。
