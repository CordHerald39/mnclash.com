Clash 常见问题解答

用 Clash 的过程中难免会遇到各种问题。这里整理了大家最常问的问题，从基础使用到故障排查，从配置技巧到进阶功能，基本都能在这找到答案。如果这里没有你要找的，可以看看具体平台的使用教程。

基础使用

Clash 是完全免费的吗？会不会突然收费？

Clash 核心程序完全开源免费，遵循 GPL-3.0 协议，代码公开在 GitHub 上任何人都能查看。各平台的图形界面客户端（Clash for Windows、ClashX、Clash Meta）也都是免费的，不存在收费计划。

不过要注意，代理节点服务需要单独购买，这个和 Clash 软件本身无关。Clash 只是一个工具，就像浏览器一样，软件免费但上网服务要付费。

Clash 合法吗？使用会有风险吗？

Clash 本身是一个开源的网络代理工具，软件本身不违法。但用它来做什么，这个就要看具体情况了。

如果是用来访问正常的国外网站，比如查学术资料、看技术文档、用 GitHub，这些都是正常的网络使用。但如果用来访问违法内容或从事违法活动，那问题就不在工具而在行为本身。

从安全角度说，从官方 GitHub 下载的 Clash 是安全的，不含病毒和后门。但要注意别从不明网站下载修改版，那些可能被植入恶意代码。

什么是订阅链接？在哪里获取？

订阅链接是一个网址，里面包含了所有节点的配置信息。把这个链接导入 Clash 后，软件会自动解析出所有节点，你就不用一个个手动添加了。

订阅链接一般是从机场服务商那里获取的。你买了服务后，他们会给你一个订阅链接，长得像这样：https://example.com/sub?token=xxxxx

有些订阅链接支持自动更新，服务商加了新节点或改了配置，你在 Clash 里点一下更新就能同步。

Clash 和 VPN 有什么区别？

虽然用起来效果差不多，但技术上完全不同：

VPN（虚拟专用网）是把你的所有流量都加密后通过一条隧道发送，通常用于企业内网访问或完全隐藏上网行为。特点是全局生效，不管什么应用都走 VPN。

Clash 是代理工具，可以根据规则智能分流：国内网站直连，国外网站走代理。这样既能访问外网，国内网站速度也不受影响。而且 Clash 支持更灵活的配置，可以针对不同网站用不同节点。

简单说，VPN 是一刀切，Clash 是精准控制。日常使用 Clash 更方便，速度也更快。

配置相关

导入订阅后没有节点怎么办？

遇到这种情况，按顺序检查这几点：

  • 订阅链接是否完整复制，有没有多余的空格或少复制了字符
  • 订阅链接是否过期，可以联系服务商确认
  • 网络环境是否正常，有些订阅链接本身需要代理才能访问
  • Clash 版本是否支持订阅中的节点协议（比如旧版本不支持 Hysteria2）

一个实用的办法是：先关闭 Clash 的代理，然后刷新订阅，看看能不能获取到节点。如果还不行，试试重启 Clash 客户端。

代理模式该选哪个？规则、全局、直连有什么区别？

规则模式（推荐）：根据配置文件里的规则自动分流。国内网站直连，国外网站走代理，某些网站可以指定特定节点。这是最常用也最省心的模式。

全局模式：所有流量都走代理，不管访问什么网站。适合临时需要完全代理的情况，但会让国内网站变慢，而且浪费流量。

直连模式：相当于关闭代理，所有流量都不走代理。适合临时需要访问银行网站、支付平台等对网络环境敏感的服务。

日常使用选规则模式就对了，方便又省流量。

规则分流是什么？怎么配置？

规则分流就是告诉 Clash：什么流量该怎么处理。比如你可以设置："所有访问 Google 的请求走香港节点，访问 Netflix 走美国节点，访问淘宝直接连接"。

规则分流的好处是：

  • 国内网站直连，速度快不浪费流量
  • 不同网站用不同节点，优化速度
  • 屏蔽广告域名，省流量

大部分订阅链接已经包含了规则，导入后直接能用。如果想自定义规则，需要编辑配置文件的 rules 部分，不过这个对新手来说有点复杂，建议先用订阅自带的规则。

如何更新订阅？多久更新一次合适？

在 Clash 的配置或订阅管理界面，找到你的订阅，点旁边的刷新或更新按钮就行。更新时 Clash 会重新下载配置文件，获取最新的节点信息。

更新频率看服务商的节点变化情况。如果服务商经常加节点或调整线路，可以每周更新一次。如果节点很稳定，一个月更新一次也够。频繁更新其实没必要，节点没变的话更新了也是一样的。

有些 Clash 客户端支持自动更新订阅，可以设置每天或每周自动拉取，就不用手动管了。

故障排查

启动 Clash 后还是无法访问外网

这是最常见的问题，一般是这几个原因：

1. 没有选择可用节点
打开 Clash 的代理界面，确认已经选中了一个节点。可以点延迟测试，看哪些节点能用。

2. 系统代理没开启
检查 Clash 的"系统代理"或"Set as system proxy"选项是否打开。Windows 和 macOS 需要手动开启这个。

3. 代理模式选错了
如果选的是"直连模式"，那相当于没开代理。改成"规则模式"或"全局模式"试试。

4. 节点失效
测试一下节点延迟，如果全部超时，说明节点不可用了，联系服务商或更新订阅。

5. 防火墙拦截
有些安全软件会拦截 Clash 的网络连接，试着把 Clash 加入白名单。

部分网站能访问，部分不能访问

这通常是规则分流的问题。Clash 根据规则判断流量走向，如果规则配置不当，就会出现有些网站能上有些不能上的情况。

临时解决办法：切换到"全局模式"，让所有流量都走代理，看看是不是规则的问题。如果全局模式下能访问，那就确定是规则需要调整。

长期解决：检查规则配置，确保目标网站匹配到正确的规则。也可以换一个规则集试试，比如 ACL4SSR 或 Loyalsoldier 这些社区维护的规则一般比较全面。

速度很慢，看视频卡顿怎么办？

代理速度慢一般是节点问题，试试这些办法：

  • 换节点 - 测试所有节点的延迟，选延迟最低的。有些节点虽然延迟低但带宽小，多试几个
  • 换协议 - 如果服务商提供多种协议节点，试试 Trojan 或 Hysteria，这些协议在某些网络环境下速度更快
  • 检查本地网络 - 先不开代理测试本地网速，如果本地网就慢，代理肯定也快不了
  • 避开高峰期 - 晚上 8-11 点是用网高峰，很多节点会变慢，可以换个时间段试试

如果所有节点都慢，那可能是服务商的问题，考虑换一家。

Clash 启动后电脑网络就断了

这种情况通常是 TUN 模式或增强模式配置有问题。TUN 模式会创建虚拟网卡接管网络流量，如果配置不当就会导致整个网络不通。

解决办法：

  • 关闭 TUN 模式或增强模式，改用普通的系统代理模式
  • 检查 Clash 的网络权限，Windows 需要管理员权限，macOS 需要授权网络扩展
  • 重启网络适配器或重启电脑

如果关闭 Clash 后网络还是不通，可能是虚拟网卡没有正确删除。Windows 可以在"网络连接"里禁用 Clash 创建的网卡，macOS 在"系统设置-网络"里删除。

进阶问题

TUN 模式和系统代理有什么区别？

系统代理是在系统层面设置一个代理地址，应用程序需要主动读取系统代理设置才会走代理。但有些应用不遵守系统代理设置，比如某些游戏、命令行工具，这些就不会走代理。

TUN 模式是创建一个虚拟网卡，把系统的所有网络流量都劫持到这个虚拟网卡，然后由 Clash 处理。这样就实现了真正的全局代理，任何应用的网络请求都会经过 Clash。

TUN 模式更彻底，但也更复杂，需要管理员权限，而且配置不当可能影响整个网络。普通使用系统代理就够了，只有在需要代理特殊应用时才开 TUN 模式。

DNS 污染是什么？Clash 如何防止 DNS 泄露？

DNS 污染是指你查询一个域名的 IP 地址时，DNS 服务器返回一个错误的 IP，导致你访问不到真实的网站。DNS 泄露是指虽然你开了代理，但 DNS 查询还是走的本地网络，可能暴露你要访问的网站。

Clash 通过内置的 DNS 服务器来解决这两个问题：

  • 使用国外的 DNS 服务器（如 1.1.1.1）解析被污染的域名
  • DNS 查询也可以通过代理，防止泄露
  • 支持 fake-ip 模式，直接返回假 IP 跳过 DNS 查询

这些配置通常在订阅里已经设置好了，不需要手动改。

Clash 支持哪些代理协议？

Clash 支持的协议很全面，主流的基本都支持：

  • Shadowsocks (SS) - 最经典的协议，稳定可靠
  • ShadowsocksR (SSR) - SS 的增强版，兼容性好
  • VMess - V2Ray 的核心协议，功能强大
  • VLESS - VMess 的轻量版，性能更好
  • Trojan - 伪装成 HTTPS 流量，隐蔽性强
  • Hysteria / Hysteria2 - 基于 QUIC 的高速协议
  • Snell - 专为 Surge 设计的协议
  • SOCKS5 / HTTP - 标准代理协议

不同版本的 Clash 支持的协议可能有差异。Clash Meta（Mihomo 内核）支持最全，基本上主流协议都能用。

如何备份 Clash 的配置？

Clash 的配置文件通常存在这些位置：

  • Windows：用户目录下的 .config/clash 或 Clash 安装目录的 profiles 文件夹
  • macOS：~/.config/clash 或应用支持目录里
  • Android：内部存储的 Clash 文件夹

备份时把整个配置文件夹复制一份就行。主要是 config.yaml（主配置文件）和 profiles 文件夹（订阅配置）。

换手机或重装系统后，把备份的配置文件夹覆盖回去，就能恢复所有设置和订阅，不用重新配置。
