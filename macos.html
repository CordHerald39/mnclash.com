安装教程（以 ClashX Meta 为例）

下载安装包
访问 GitHub Releases 页面，下载最新版本的 .dmg 文件。
安装应用
双击 .dmg 文件，将 ClashX Meta 拖到 Applications 文件夹。
打开应用
在 Launchpad 或 Applications 文件夹中找到 ClashX Meta，双击打开。首次打开可能提示"无法验证开发者"，去"系统设置" → "隐私与安全性" → 点击"仍要打开"。
安装辅助工具
首次启动会提示安装辅助工具（用于修改系统代理设置），输入 macOS 密码允许安装。
导入订阅
点击菜单栏的 ClashX 图标，选择"配置" → "托管配置" → "管理" → "添加"，粘贴订阅链接，点击"确定"。
启动代理
点击菜单栏图标，选择"设置为系统代理"。再选择"代理模式" → "规则判断"。就可以正常使用了。
Gatekeeper 提示说明：首次打开时 macOS 可能提示"无法验证开发者"。这是因为应用没有苹果的公证。去"系统设置" → "隐私与安全性"，找到 ClashX Meta，点击"仍要打开"即可。从 GitHub 官方下载的版本是安全的。

代理模式说明

ClashX 提供三种代理模式：

1. 规则判断（推荐）

根据配置文件的规则自动分流。国内网站直连，国外网站走代理。这是最常用的模式。

2. 全局连接

所有流量都走代理。适合需要完全隐藏真实 IP 的场景。

3. 直接连接

所有流量都不走代理。相当于暂时关闭代理。

新手建议：始终使用"规则判断"模式。配置文件通常已经包含了常用的分流规则，无需手动调整。

增强模式（TUN）

ClashFX 支持增强模式（TUN），可以代理所有应用的流量，不仅是浏览器。这对于需要代理的命令行工具、GUI 应用很有用。

如何开启增强模式

  1. 打开 ClashFX
  2. 在设置中找到"增强模式"或"TUN Mode"
  3. 开启后所有应用的流量都会经过 Clash
注意：ClashX Meta 不支持 TUN 模式，只有 ClashFX 和 Clash Verge Rev 支持。如果你需要这个功能，选择 ClashFX。

常见问题

Q: ClashX 和 ClashX Meta 有什么区别？

ClashX 是原版，基于老的 Clash 核心。ClashX Meta 基于更新的 Clash Meta 核心，支持更多协议和功能。新用户直接用 ClashX Meta。
Q: 我该选 ClashX Meta 还是 ClashFX？

如果只是日常浏览网页，ClashX Meta 足够了。如果需要代理所有应用（TUN 模式），选 ClashFX。
Q: 为什么打开时提示"无法验证开发者"？

这是 macOS 的安全机制。去"系统设置" → "隐私与安全性"，找到对应应用，点击"仍要打开"即可。
Q: Apple Silicon Mac 能用吗？

完全可以。所有推荐的客户端都原生支持 M1/M2/M3 芯片，性能和稳定性都很好。
Q: 订阅链接从哪里获取？

订阅链接由你的服务提供商提供。如果你没有服务，需要先购买或搭建自己的服务器。
