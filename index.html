常见问题

Clash 是什么？

Clash 是一个开源的跨平台代理工具，支持多种代理协议和规则分流，可以帮助用户实现智能网络访问。它支持 Windows、macOS、Android、iOS 等主流平台。

Clash 免费吗？

Clash 客户端本身是完全免费开源的软件。但使用 Clash 需要配合代理服务器使用，服务器节点通常由第三方服务商提供，可能需要付费订阅。

如何获取 Clash 订阅链接？

订阅链接需要从代理服务提供商处获取。购买服务后，服务商会提供订阅链接，将链接复制到 Clash 客户端即可导入所有节点配置。

Clash 规则分流是什么？

规则分流是指根据预设规则，自动判断哪些网站走代理、哪些直连。比如国内网站直连，国外网站走代理，可以提高访问速度并节省流量。

Clash 支持哪些协议？

Clash 支持 Shadowsocks (SS)、ShadowsocksR (SSR)、VMess、Trojan、Snell、SOCKS5、HTTP(S) 等多种代理协议，兼容性非常好。
