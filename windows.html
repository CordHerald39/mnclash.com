安装教程（以 Clash Verge Rev 为例）

下载安装包
访问 GitHub Releases 页面，下载最新版本的安装包。普通电脑选择 Clash.Verge_xxx_x64-setup.exe。
运行安装程序
双击下载的 .exe 文件，如果出现 Windows Defender SmartScreen 警告，点击"更多信息" → "仍要运行"。这是因为软件没有微软代码签名，不是病毒。
完成安装
按提示完成安装，软件会自动启动。首次启动会在系统托盘（任务栏右下角）显示图标。
导入订阅
点击托盘图标，选择"订阅" → "新建" → 粘贴订阅链接 → 点击"导入"。等待配置文件下载完成。
选择节点
点击"代理"标签，选择想用的节点。可以点击节点右侧的"测速"按钮测试延迟。
启动代理
点击主界面的"启动"按钮（或托盘图标 → "系统代理" → "开启"）。浏览器就能访问外网了。
Windows Defender 误报说明：部分杀毒软件可能误报 Clash 客户端为病毒。这是因为代理软件会修改系统网络设置，触发了杀毒软件的启发式检测。从 GitHub 官方下载的版本是安全的，可以添加到白名单。

系统代理模式

Clash 提供三种系统代理模式：

1. 规则模式（推荐）

根据配置文件的规则自动分流。国内网站直连，国外网站走代理。这是最常用的模式，兼顾速度和功能。

2. 全局模式

所有流量都走代理。适合需要完全隐藏真实 IP 的场景，但会导致访问国内网站变慢。

3. 直连模式

所有流量都不走代理。相当于暂时关闭代理，适合临时需要真实 IP 的情况。

新手建议：始终使用"规则模式"。配置文件通常已经包含了常用网站的分流规则，无需手动调整。

TUN 模式（高级功能）

TUN 模式可以代理所有应用的流量，不仅是浏览器。开启后，游戏、客户端软件等也能走代理。

如何开启 TUN 模式

  1. 打开 Clash Verge Rev 设置
  2. 找到"TUN 模式"选项，点击开启
  3. 首次开启需要管理员权限，点击"允许"
  4. 开启后所有应用的流量都会经过 Clash
注意：TUN 模式需要管理员权限，部分杀毒软件可能会拦截。如果遇到问题，先尝试关闭 TUN 模式使用普通系统代理。

常见问题

Q: Clash Verge Rev 和原版 Clash Verge 有什么区别？

Clash Verge 原作者停止维护后，社区开发者 fork 了项目继续开发，就是 Clash Verge Rev。Rev 版本功能更强，支持最新的 Meta 核心，且持续更新。
Q: 为什么安装时提示"Windows 已保护你的电脑"？

这是因为软件没有微软的代码签名证书。点击"更多信息" → "仍要运行"即可。从 GitHub 官方下载的版本是安全的。
Q: 可以和其他 VPN 软件同时使用吗？

不建议。同时运行多个代理软件可能导致冲突，造成网络异常。使用 Clash 时关闭其他 VPN 软件。
Q: 订阅链接从哪里获取？

订阅链接由你的服务提供商提供。如果你没有服务，需要先购买机场订阅或搭建自己的服务器。
Q: FlClash 和 Clash Verge Rev 该选哪个？

功能需求高选 Clash Verge Rev，追求简洁轻量选 FlClash。新手建议 Clash Verge Rev，功能更全面。

2026 年在 Windows 上使用 Clash，首选 Clash Verge Rev。它是社区维护的，功能最强大，更新最及时，社区支持也最好。原版 Clash for Windows 已经停止维护，不要再使用了。
